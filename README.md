# 3DモデルARビューア（プロトタイプ v0.1）

中学校 技術・家庭科 技術分野「A 材料と加工の技術」向け。
「作ってみよう！」等のCADで作った3Dモデル（GLB）を、印刷したマーカーの上に
AR表示し、その場で写真を撮って保存できる Webアプリ。

- 対象端末：**Chromebook**（Chrome）。Windows / Android / iPad の Chrome・Safari でも動作。
- 方式：**マーカー型AR**（AR.js / ARToolKit）
- インストール不要。**静的ファイルのみ**でサーバ処理なし。モデルは端末外に送信されない。

---

## 1. 既存アプリとの違い（なぜ作り直したか）

| | 既存アプリ | 本アプリ |
|---|---|---|
| モデルの向き | 生徒がプルダウンで回転角を指定 | **自動で直立**（Z-up CADを検出して補正） |
| モデルの大きさ | 生徒が数値を指定（Tinkercadは「100」が必要） | **自動でマーカー基準に正規化** |
| 位置 | 手動 | **自動で中央・接地** |
| 撮影 | なし | **アプリ内シャッターボタン**（カメラ映像＋モデルを合成してPNG保存） |
| 動き | 常時自動回転 | 既定は静止（「ゆっくり回す」は任意） |
| ちらつき | 対策なし | マーカー平滑化（smooth）を有効化 |
| 外部通信 | パターン／カメラ校正データを外部サイトから取得 | **すべて同梱**。学校ネットワークで完結 |
| ファイル上限 | 2MB | サーバに送らないため上限なし（端末性能に依存） |

## 2. 使い方

1. **マーカーを印刷** … アプリ内の「マーカーを印刷する」→ A4に等倍印刷し、平らな机に置く。
2. **GLBを用意** … 「作ってみよう！」で〔保存〕→ ファイル形式に **`.glb`** を選んで書き出す。
3. **アプリでGLBを選ぶ** … 向き・大きさは自動調整。プレビューで確認できる（ドラッグで回転）。
4. **［ARをはじめる］** … カメラの使用を「許可」する。
5. マーカーを写すとモデルが立ち上がる。**丸いシャッターボタン**で撮影 →［写真を保存］。

写真は端末の「ダウンロード」フォルダに `AR_20260909_143012.png` の形式で保存される。

---

## 3. 動かし方（ホスティング）

カメラは **`https://` または `localhost`** でしか使えない。`file://` で直接開いても動かない。

### 手元で試す

```bash
cd ar-glb-viewer
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### 学校で配る

`ar-glb-viewer` フォルダをまるごと静的ホスティングへ置く（GitHub Pages / Google Cloud Storage /
校内Webサーバ等）。ビルド不要。外部CDNへの依存はない。

## 5. 既知の制約

- **マーカーが見えている間だけ**表示される（マーカー型ARの原理上の制約）。
- 光の反射でマーカーが白とびすると認識しない。斜め上からの照明が安定する。
- 三角形数が非常に多いモデルはChromebookで重くなる。目安 10万三角形以下。
- 独自 `.patt` を使う場合、パターン画像も各自で印刷する必要がある。

## 6. テスト

向き・大きさの自動正規化ロジック（このアプリの中核）には数値テストがある。
`js/app.js` から実際の関数を抜き出して実行するので、コードのコピーではなく本体を検証する。

```bash
cd test && node fit.test.mjs
```

検証内容：Z-up CAD／Y-up／極小モデルの向き判定、最大辺の正規化、接地、水平中央寄せ、
手動での向き上書き、浮かせ、そして**マーカーが動いても正規化結果が変わらないこと**。
